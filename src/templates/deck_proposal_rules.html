HTML & Content Sanitization

Cleans contributor quirks upon ingestion while preserving textual knowledge. All rules are natively disabled by default.

Strips text color and background-color declarations, preserving general deck typography.

Strips opening and closing span elements while retaining the inner text, preventing formatting collisions.

Strips centering tags and text-align: center on answer fields, ensuring clear left-aligned readability.

Automatically repairs cloze typos like single colons {{c1:text}} into valid {{c1::text}}.

HTML Directives Reference
Directive Syntax Example Action
strip-tags: strip-tags: span, font, em Unwraps the outer tags, keeping inner text intact
remove-elements: remove-elements: script, iframe Completely deletes the tags and everything inside them
strip-styles: strip-styles: color, font-family Removes specific CSS properties from style attributes
strip-attributes: strip-attributes: class, id, dir Removes unwanted attributes across all HTML elements
strip-empty: strip-empty: span, div, b, i Deletes empty tags that contain only whitespace
replace: replace: "old" => "new" Performs exact literal string substitution
regex-replace: regex-replace: /foo\d+/ => "bar" Performs regex pattern search and replacement
